EMOTIQ drop-in / EMOTIQ einlegen
================================

DE: Die lizenzierte EMOTIQ-Datei (© Enxyclo Studio) hier ablegen als
    EMOTIQ.woff2, EMOTIQ.woff, EMOTIQ.otf oder EMOTIQ.ttf -
    das Theme erkennt sie von selbst und die Display-Schrift wechselt
    von Audiowide auf EMOTIQ, vorne wie im Editor. Nichts weiter nötig.
    scripts/build-zip.sh packt hier liegende Dateien mit ins Theme-Zip.

EN: Place the licensed EMOTIQ file (© Enxyclo Studio) here as
    EMOTIQ.woff2, EMOTIQ.woff, EMOTIQ.otf or EMOTIQ.ttf - the theme
    detects it and the display face switches from Audiowide to EMOTIQ,
    front end and editor alike. Nothing else to configure.
    scripts/build-zip.sh includes files placed here in the theme zip.

Font binaries in this folder stay out of git (public repo, font license)
- only this README is committed.
